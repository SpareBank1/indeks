# ListCard

ListCard samler rader som hører sammen i ett kort, for eksempel kontoene til en kunde eller
valgene du har på en konto. Kortet kan ha en header med tittel og en tekst til høyre, som en sum.

## Egnet til

- En liste med valg der hver rad leder videre, som innstillinger eller handlinger på en konto
- En oversikt over flere ting av samme slag, som kontoer, kort eller faste betalinger
- Detaljer om én ting, der hver rad er ett felt med en verdi

## Uegnet til

- Ett enkelt valg som skal stå for seg selv. Bruk heller [Card](./card)
- Innhold som ikke er rader, som tekst, bilder eller skjema. Bruk heller [Surface](./surface)
- Data som skal sammenlignes i kolonner

## Universell utforming

### Hva du selv må sørge for

- Velg overskriftsnivå ut fra overskriften over kortet. Tittelen er `h3` som standard. Står kortet rett under sidens `h1`, bruk `h2`.
- Skriv en tittel som sier hva lista inneholder. Den blir også navnet på lista.
- Skriv teksten til høyre i headeren så den kan leses alene: «Totalt: 42 672 kr», ikke bare «42 672 kr».
- Følg reglene for [Row](./row) i hver rad. Det interaktive ligger i raden, ikke i kortet.

### Hva komponenten gjør automatisk

- Radene ligger i en liste, og skjermlesere leser antallet når brukeren kommer inn i den. `role="list"` står eksplisitt, fordi VoiceOver i Safari ellers fjerner liste-semantikken.
- I React kobles tittelen til lista med `aria-labelledby`. I HTML setter du `id` og `aria-labelledby` selv.
- Fokusringen i radene klippes ikke av kortets avrundede hjørner.

## Props / API

<Tabs groupId="variant">
<TabItem value="html" label="HTML">

| Element | Beskrivelse |
|---------|-------------|
| `.ix-list-card` | Kortet. Påkrevd |
| `.ix-list-card__header` | Headeren. Valgfri |
| `.ix-list-card__title` | Tittelen i headeren, på en overskrift. Gi den en `id` |
| `.ix-list-card__trailing` | Tekst til høyre i headeren |
| `ul role="list"` | Lista med rader. Sett `aria-labelledby` til tittelens `id` |

</TabItem>
<TabItem value="react" label="React">

| Prop | Type | Standard | Beskrivelse |
|------|------|----------|-------------|
| `title` | `ReactNode` | | Tittel i headeren. Gir også lista navn |
| `titleAs` | `'h2'`–`'h6' \| 'p' \| 'span'` | `'h3'` | Elementet tittelen rendres som |
| `trailing` | `ReactNode` | | Tekst til høyre i headeren, f.eks. en sum |
| `children` | `ReactNode` | | Én `<Row>` per rad. Hvert barn legges i sin egen `<li>` |

Andre props, som `className` og `data-*`, sendes til rot-elementet.

</TabItem>
</Tabs>

## Tilpasning med CSS

Du kan bygge ListCard med klassene alene. React-komponenten setter de samme klassene og
legger ikke til noe utover dem.

### Tilgjengelige klasser og selektorer

| Element | Selektor |
|---------|----------|
| Kort | `.ix-list-card` |
| Header | `.ix-list-card__header` |
| Tittel | `.ix-list-card__title` |
| Tekst til høyre | `.ix-list-card__trailing` |
| Liste | `.ix-list-card > ul` |
| Rad i lista | `.ix-list-card > ul > li` |

### Eksempel: ren HTML

```html
<div class="ix-list-card">
  <div class="ix-list-card__header">
    <h3 class="ix-list-card__title" id="mine-kontoer">Kontoer</h3>
  </div>
  <ul role="list" aria-labelledby="mine-kontoer">
    <li>
      <div class="ix-row">
        <div class="ix-row__body">
          <div class="ix-row__content">
            <p class="ix-row__title"><a class="ix-row__action" href="/konto/1">Brukskonto</a></p>
          </div>
        </div>
        <ix-icon class="ix-row__nav-icon" name="keyboard_arrow_right" aria-hidden="true"></ix-icon>
      </div>
    </li>
  </ul>
</div>
```
