# Card

Card presenterer innhold og navigasjon i én samlet, klikkbar flate. Hele kortet leder til ett sted, og et ikon viser om du blir værende på siden eller åpner en ekstern side. Kortet finnes i en kompakt variant og i to mediarike varianter med bilde eller illustrasjon.

## Egnet til

- Inngang til en konto, et produkt eller en tjeneste (f.eks. en liste over kontoer på forsiden)
- Navigasjon videre til en underside der kortet oppsummerer hva du finner der
- Innhold som skal vises med bilde eller illustrasjon, f.eks. produkter eller artikler
- Oppfordring til å opprette noe nytt (stiplet variant)

## Uegnet til

- Innhold som ikke leder noe sted — bruk [Surface](./surface) for å gruppere innhold
- Kort med flere handlinger, knapper eller lenker inni — bruk [Surface](./surface) med vanlige knapper og lenker
- Handlinger som utfører noe på siden (lagre, slette, åpne dialog) — bruk [Button](./button)
- Lenker i løpende tekst

Kortet er én lenke: tittelen er en ekte `<a>`, og klikkflaten strekkes over hele kortet med CSS. Det finnes derfor bare ett mål for tastatur og skjermleser, mens musebrukere kan klikke hvor som helst på flaten.

### Router-lenke

I React kan du bruke lenkekomponenten fra routeren din i stedet for `<a>`, så navigasjonen skjer uten full sidelasting. Send komponenten inn i `linkAs`, og dens egne props i `linkProps`. `href` er valgfri når `linkAs` er satt, og sendes videre hvis du oppgir den. `linkAs` kan ikke kombineres med `external`. I HTML bytter du bare ut `<a class="ix-card__link">` med lenken routeren rendrer.

```tsx
// React Router
import { Link } from 'react-router';

<Card linkAs={Link} linkProps={{ to: '/konto' }} title="Brukskonto" />;

// Next.js
import NextLink from 'next/link';

<Card linkAs={NextLink} href="/konto" title="Brukskonto" />;
```

## Retningslinjer

### La tittelen fortelle hvor kortet leder

Tittelen er lenketeksten. Skjermleserbrukere hører den alene når de lister opp lenker på siden, så den må gi mening uten resten av kortet. Skriv «Brukskonto» eller «Boliglån», ikke «Les mer» eller «Gå videre». Har flere kort samme tittel, gjør dem unike.

### Ett kort, ett mål

Hele kortet er én lenke. Legg ikke knapper, lenker, avkrysningsbokser eller andre interaktive elementer inni — de havner under klikkflaten, blir vanskelige å treffe og gir to mål på samme sted. Trenger innholdet flere handlinger, bruk [Surface](./surface) med vanlige knapper og lenker.

### Velg riktig overskriftsnivå

Tittelen er en `<h3>` som standard. Velg nivået som passer i sideoversikten — står kortene rett under sidens hovedoverskrift, bruk `h2`. Skal kortene ikke inngå i overskriftsstrukturen, bruk `span`. I React settes dette med `titleAs`; i HTML bytter du elementet.

### Bilder er som regel dekorative

Tittelen bærer meningen, så bilder og illustrasjoner i kortet er normalt dekorative og skal ha `alt=""`. Gi bildet en beskrivende alt-tekst bare når det formidler noe som ikke står i teksten.

### Bruk stiplet variant for å opprette noe nytt

Den stiplede varianten skiller «legg til»-kort fra eksisterende innhold. Bruk den sammen med et pluss-ikon, og plasser den etter de eksisterende kortene i listen.

## Universell utforming

### Hva du selv må sørge for

- Skriv en tittel som forteller hvor kortet leder. Tittelen er lenkenavnet skjermlesere leser opp, og må være unik og beskrivende uten resten av kortet.
- Velg overskriftsnivå som passer i sidens struktur (`titleAs` i React).
- Send inn `externalLabel` på brukerens språk når kortet leder til en ekstern side, f.eks. «(åpnes i ny fane)», «(opnar i ny fane)» eller «(opens in a new tab)». Komponenten har ingen innebygd tekst.
- Gi bilder alt-tekst. Dekorative bilder og illustrasjoner skal ha `alt=""`.
- Ikke legg andre interaktive elementer inni kortet.

### Hva komponenten gjør automatisk

- **Én ekte lenke** — tittelen er en native `<a>`, så tastatur, kontekstmeny («Åpne i ny fane») og skjermleser fungerer uten JavaScript.
- **Hele kortet er klikkflaten** — lenkens klikkflate strekkes over hele kortet med CSS.
- **Fokusring rundt hele kortet** ved `:focus-visible`, ikke bare rundt tittelteksten.
- **Navigasjonsikonet er skjult for skjermlesere** (`aria-hidden`), så det ikke forstyrrer lenkenavnet.
- **Ekstern lenke** får `target="_blank"` og `rel="noopener noreferrer"`, og `externalLabel` legges til lenkenavnet som skjult tekst.
- **Redusert bevegelse** — overganger slås av når brukeren har valgt det i operativsystemet.
- **Høykontrastmodus** — kant og fokusring bruker systemfarger i Windows høykontrast.

## Props / API

| Prop | Type | Standard | Beskrivelse |
|------|------|----------|-------------|
| `href` | `string` | | Påkrevd, unntatt med `linkAs`. Hvor kortet leder |
| `title` | `ReactNode` | | Påkrevd. Tittelen — er også lenketeksten |
| `titleAs` | `'h2' \| 'h3' \| 'h4' \| 'h5' \| 'h6' \| 'span'` | `'h3'` | Overskriftsnivå for tittelen |
| `subtitle` | `ReactNode` | | Kort tekst under tittelen |
| `variant` | `'small' \| 'large-vertical' \| 'large-horizontal'` | `'small'` | Oppsett |
| `appearance` | `'default' \| 'dashed'` | `'default'` | Kun `small`. `dashed` gir stiplet, gjennomsiktig flate i hvile |
| `leading` | `ReactNode` | | Kun `small`. Ikon eller illustrasjon foran tittelen |
| `leadingType` | `'icon' \| 'icon-background' \| 'illustration'` | `'icon'` | Kun `small`. Hvordan `leading` vises |
| `media` | `ReactNode` | | Kun `large-*`. Bilde eller illustrasjon |
| `mediaType` | `'image' \| 'illustration'` | `'image'` | Kun `large-*`. `image` fyller flaten, `illustration` sentreres |
| `description` | `ReactNode` | | Kun `large-*`. Lengre beskrivelse |
| `tag` | `ReactNode` | | Kun `large-*`. Én eller flere [Tag](./tag) |
| `external` | `boolean` | `false` | Åpner lenken i ny fane og viser `open_in_new`-ikonet |
| `externalLabel` | `string` | | Påkrevd når `external` er satt. Skjult tekst lagt til lenkenavnet |
| `linkAs` | `ElementType` | | Router-lenke i stedet for `<a>`, f.eks. `Link` fra React Router eller Next. Kan ikke kombineres med `external` |
| `linkProps` | `AnchorHTMLAttributes` / props til `linkAs` | | Ekstra props til lenken, f.eks. `onClick`, `aria-current` eller `to`. Typen følger `linkAs` |

Øvrige HTML-attributter (`id`, `className`, `data-*` osv.) settes på rotelementet (`<div>`). TypeScript hindrer deg i å kombinere props som ikke hører til varianten, f.eks. `media` på `small`.

## Tilpasning med CSS

Trenger du `ix-card`-stylingen på HTML du setter sammen selv, uten React-komponenten, kan du bruke klassene direkte. Card har ingen web component — alt styres med klasser og attributter.

### Tilgjengelige klasser og selektorer

| Element/tilstand | Selektor / attributt |
|-----------------|----------------------|
| Kort | `.ix-card` |
| Variant | `data-variant="small"` / `"large-vertical"` / `"large-horizontal"` |
| Stiplet (kun small) | `data-appearance="dashed"` |
| Leading (kun small) | `.ix-card__leading` med `data-type="icon"` / `"icon-background"` / `"illustration"` |
| Media (kun large) | `.ix-card__media` med `data-type="image"` / `"illustration"` |
| Innhold | `.ix-card__content` |
| Tittelrad | `.ix-card__heading` |
| Tittel | `.ix-card__title` (på `h2`–`h6` eller `span`) |
| Lenke | `.ix-card__link` (på `<a>` inni tittelen) |
| Navigasjonsikon | `.ix-card__nav-icon` (`arrow_forward` eller `open_in_new`) |
| Undertittel | `.ix-card__subtitle` |
| Beskrivelse (kun large) | `.ix-card__description` |
| Tags (kun large) | `.ix-card__tags` |
| Skjult tekst for ekstern lenke | `.ix-sr-only` inni lenken |

### Eksempel: ren HTML

```html
<div class="ix-card" data-variant="large-horizontal">
  <div class="ix-card__media" data-type="image">
    <img src="/bilder/bolig.jpg" alt="" />
  </div>
  <div class="ix-card__content">
    <div class="ix-card__heading">
      <h2 class="ix-card__title">
        <a class="ix-card__link" href="https://example.com" target="_blank" rel="noopener noreferrer">
          Boliglån <span class="ix-sr-only">(åpnes i ny fane)</span>
        </a>
      </h2>
      <ix-icon class="ix-card__nav-icon" name="open_in_new" aria-hidden="true"></ix-icon>
    </div>
    <p class="ix-card__subtitle">Fra 4,9 % effektiv rente</p>
    <p class="ix-card__description">Se hva du kan låne.</p>
    <div class="ix-card__tags">
      <span class="ix-tag">Nyhet</span>
    </div>
  </div>
</div>
```

Lenken må ligge inni `.ix-card__title`, og `.ix-card` må ikke ha `overflow: hidden` eller egen `position` overstyrt — klikkflaten og fokusringen er tegnet av lenkens `::after`, som er posisjonert mot kortet.
