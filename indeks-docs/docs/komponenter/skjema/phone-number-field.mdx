# PhoneNumberField

PhoneNumberField lar brukeren oppgi et telefonnummer med landkode. Komponenten består av to tekstfelt under én felles label: et **landkodefelt** med «+» foran, og et **nummerfelt** som formateres mens brukeren skriver. Det er to uavhengige felt, men gruppen har én felles feilmelding.

:::info Sammensatt komponent
PhoneNumberField grupperer to [TextField](./textfield). Nummerfeltet bruker [formatering](./textfield-formatering). Formatering, feltets ARIA og form-synk kommer uendret fra TextField.
:::

## Egnet til

- Skjemaer der brukeren skal oppgi telefonnummer med landkode
- Skjemaer der landkoden skal vises, men ikke kunne endres (låst landkode)

## Uegnet til

- Rene norske nummer der landkode er unødvendig. Bruk `hideCountryCode`, eller et vanlig [TextField](./textfield) med `format="phone"`
- Situasjoner der brukeren skal velge land fra en liste. Komponenten har ingen landvelger

```jsx live
      </div>
    </ix-field>
    <ix-field data-field="number" class="ix-field">
      <div class="ix-text-field">
        <input aria-label="Telefonnummer" name="tlf" />
      </div>
    </ix-field>
  </div>
  <span data-field="error"></span>
</ix-phone-number-field>
```

Du skriver to `<ix-field>` med `.ix-text-field` og en felles feilmelding. `<ix-phone-number-field>` gjør resten:

- **Stamper standardattributter** når de mangler. Landkoden får `inputmode="numeric"` og `autocomplete="tel-country-code"`. Nummeret får `type="tel"`, `inputmode="numeric"`, `autocomplete="tel-national"` og `data-format="phone"`.
- **Renser landkoden:** bare sifre, maks tre. Autofyll gir «+47», og «+» og andre tegn fjernes.
- **Setter gruppe-ARIA:** `role="group"`, `aria-labelledby` til `data-field="legend"`, og `aria-describedby` til beskrivelse og feilmelding.
- **Propagerer** `disabled`, `readonly` og `required` til begge feltene.

### To felt i React Hook Form

Landkoden og nummeret er to uavhengige felt. I React binder du dem med hver sin registrering, `countryField` og `numberField`, som spres rett på delfeltene:

- **`countryField={register('landkode')}`:** `event.target.value` er sifrene uten `+`, f.eks. `"47"`.
- **`numberField={register('tlf')}`:** `event.target.value` er det **rå** nummeret, uten mellomrom.

Gruppen har bare én feilmelding. Velg den viktigste med `??`:

```tsx
function Skjema() {
  const { register, handleSubmit, formState: { errors } } = useForm({
    defaultValues: { landkode: '47', tlf: '' },
  });
  return (
    <Form onSubmit={handleSubmit(console.log)} noValidate>
      <PhoneNumberField
        label="Mobilnummer"
        description="Norsk format: 123 45 678"
        countryLabel="Landkode"
        numberLabel="Telefonnummer"
        countryField={register('landkode', { required: 'Skriv inn landkode' })}
        numberField={register('tlf', { pattern: { value: /^\d{8}$/, message: 'Åtte siffer' } })}
        errorMessage={errors.landkode?.message ?? errors.tlf?.message}
      />
    </Form>
  );
}
```

`defaultCountryCode` er start-landkoden når registreringen ikke selv seeder verdien. Sett den samme verdien i `defaultValues`, så skjemaet og feltet er i synk.

## Retningslinjer

### Landkoden tar bare sifre

- Maks tre sifre
- «+» og andre tegn fjernes automatisk, så autofyll med «+47» gir `47`
- Verdien er alltid sifrene uten «+»

### Gjør nummerfeltet bredere enn landkoden

Er de to feltene like brede, ser de ut som to like felt, og brukeren begynner å skrive nummeret i det første. Bredden viser hvilket felt som er hovedfeltet.

### Send eget format for andre land enn Norge

Standarden er norsk 8-sifret (`123 45 678`) uansett landkode. Andre nummerlengder krever `numberFormat` eller `numberFormatPattern`. Formateringen er bare visuell: verdien som sendes, er alltid rå og uten mellomrom.

## Universell utforming

### Gruppe med felles navn

`<ix-phone-number-field>` setter `role="group"` og kobler den felles labelen (`data-field="legend"`) via `aria-labelledby`. Skjermlesere annonserer de to feltene som én gruppe med et felles navn. Begge feltene er vanlige tekstfelt med eget navn via `aria-label`.

### Feltets formål eksponeres (1.3.5)

Landkoden får `autocomplete="tel-country-code"` og nummeret `autocomplete="tel-national"` (når de mangler). Mobilt tastatur viser tall, og nettleseren kan autofylle begge feltene.

### Én feilmelding for gruppen

Feilmeldingen ligger på gruppen. `aria-invalid="true"` settes på gruppen, og meldingen annonseres `polite` via `aria-live`. Med to RHF-felt velger du selv hvilken melding som vises (`errors.landkode?.message ?? errors.tlf?.message`).

### Fokusrekkefølge og tastatur

Tab flytter fokus fra landkode til nummerfelt, som er leserekkefølgen. Begge er vanlige tekstfelt.

### Send inn oversatt tekst (i18n)

`label`, `description`, `countryLabel`, `numberLabel` og feilmeldingen må sendes inn på riktig språk (bokmål, nynorsk, engelsk). Det finnes ingen fallback.

### `<ix-phone-number-field>`

| Attributt | Påkrevd | Beskrivelse |
|-----------|---------|-------------|
| `disabled` | Nei | Deaktiverer begge feltene |
| `readonly` | Nei | Skrivebeskytter begge feltene |
| `required` | Nei | Markerer begge `<input>`-ene som påkrevd |

### Delelementer (light DOM)

| Del | Påkrevd | Beskrivelse |
|-----|---------|-------------|
| `[data-field="legend"]` | Ja | Felles label. Kobles via `aria-labelledby` |
| `[data-field="description"]` | Nei | Felles hjelpetekst. Kobles via `aria-describedby` |
| `[data-field="items"]` | Ja | Wrapper for feltene (side-ved-side-layout) |
| `[data-field="country"]` | Nei | `<ix-field>` med `.ix-text-field`, `<div data-field="prefix">+</div>` og en `<input>` med `aria-label`. Utelat for å skjule landkoden. `readonly` på inputen låser den |
| `[data-field="number"]` | Ja | `<ix-field>` med `.ix-text-field` og en `<input>` med `aria-label` |
| `[data-field="error"]` | Nei | Felles feilmelding. Ikke-tomt innhold gir `aria-invalid` på gruppen og polite annonsering |

I tillegg støttes øvrige HTML-attributter (`aria-*`, `data-*`, `tabIndex`, osv.). De sendes til `<ix-phone-number-field>`-**host-elementet**, ikke delfeltene.

### FieldRegistration

Struktur-typen `countryField` og `numberField` tar. Matcher det React Hook Form `register()` returnerer, men pakka har ingen RHF-avhengighet, så egne handlers eller `<Controller>` fungerer også.

| Felt | Type | Beskrivelse |
|------|------|-------------|
| `name` | `string` | Feltnavn ved form-innsending |
| `onChange` | `(event) => unknown` | Får et event der verdien ligger i `event.target.value` |
| `onBlur` | `(event) => unknown` | Touched-state / `mode: 'onBlur'` |
| `ref` | `Ref` | Videresendes til delfeltet |
