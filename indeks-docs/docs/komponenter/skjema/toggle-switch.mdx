# ToggleSwitch

ToggleSwitch lar brukeren slå en innstilling av eller på. Endringen gjelder med en gang, uten at brukeren må lagre.

## Egnet til

- Innstillinger som kan slås av og på
- Endringer som skal gjelde med en gang
- Enkle valg mellom av og på
- Preferanser brukeren endrer ofte

## Uegnet til

- Valg som skal sendes inn eller bekreftes etterpå. Bruk heller [Checkbox](./checkbox)
- Valg mellom flere enn to alternativer. Bruk heller [RadioGroup](./radio-group)
- Handlinger som er vanskelige å angre eller har store konsekvenser

## Retningslinjer

### Bruk switch når endringen skjer med en gang

En switch lover at innstillingen gjelder idet brukeren flytter den. Må brukeren trykke «Lagre» eller bekrefte etterpå, brytes det løftet. Bruk da [Checkbox](./checkbox).

### Beskriv tilstanden i labelen

Skriv det som gjelder når switchen er på. «Motta varsler» er tydeligere enn «Aktiver varsler», fordi brukeren ser med en gang hva av og på betyr. La labelen være den samme i begge tilstander.

### Velg én labelplassering og hold deg til den

Labelen kan stå til venstre eller til høyre for switchen. Bruk samme plassering i hele løsningen, så brukeren vet hvor hen skal se.

### Høyrejuster switchen i lister og tabeller

Står flere switcher under hverandre, for eksempel i en liste med innstillinger, kan du gi dem full bredde. Da står switchene på linje, og det blir lettere å sammenligne radene.

### Bruk tydeligere handlinger når noe er vanskelig å angre

Det er lett å slå en switch av og på ved et uhell. Kan endringen få store konsekvenser, som å sperre et kort eller avslutte en avtale, trenger brukeren en knapp og en bekreftelse.

### Grupper innstillingene når det blir mange

Mange switcher i samme visning blir fort uoversiktlig. Del dem i grupper med overskrifter, eller vurder om noen hører hjemme på en egen side.

### Tenk deg om før du deaktiverer

En deaktivert switch sier ikke hvorfor brukeren ikke kan endre den. Forklar årsaken i hjelpeteksten, skjul switchen, eller vis verdien som vanlig tekst.

## Universell utforming

### Hva du selv må sørge for

- Skriv en label som beskriver tilstanden, ikke handlingen. Ikke bytt labelteksten til «På» eller «Av», skjermleseren leser tilstanden selv.
- Uten synlig label må switchen ha `aria-label` (`ariaLabel` i React) på brukerens språk.
- Bruk switch bare når endringen gjelder med en gang.
- Endrer switchen innhold et annet sted på siden, må du si fra om resultatet, for eksempel med en statusmelding.
- Forklar hvorfor en switch er deaktivert.

### Hva komponenten gjør automatisk

- Native `<input type="checkbox">` med `role="switch"`. Skjermleseren sier at det er en bryter og om den er av eller på.
- Labelen er klikkflaten og er minst 44 px høy, også uten synlig tekst.
- Av og på skiller seg på knottens posisjon, ikke bare på farge.
- Fokusringen vises rundt label og switch når du bruker tastaturet.
- I `<ix-field>` kobles hjelpeteksten til med `aria-describedby`.
- Med redusert bevegelse hopper knotten i stedet for å gli.

## Props / API

<TabItem value="html" label="HTML">

### Struktur

```html
<ix-field>
  <div class="ix-toggle-switch" data-label-placement="right">
    <input type="checkbox" role="switch" id="varsler" name="varsler" />
    <label for="varsler">Motta varsler</label>
    <span data-field="description">Vi sender varsel på SMS</span>
  </div>
</ix-field>
```

| Del | Påkrevd | Beskrivelse |
|-----|---------|-------------|
| `<ix-field>` | Nei | Kobler `aria-describedby` fra input til hjelpeteksten. Trengs bare når du har hjelpetekst |
| `<div class="ix-toggle-switch">` | Ja | Wrapper. Holder input, label og hjelpetekst |
| `<input type="checkbox" role="switch">` | Ja | Selve switchen. Visuelt skjult, men i DOM for tastatur og skjermleser |
| `<label>` | Ja | Labeltekst og klikkflate, rett etter input. Kobles med `for`/`id`. Står tom når switchen bare har `aria-label` |
| `<span data-field="description">` | Nei | Hjelpetekst under labelen |

### Attributter

| Attributt | Plassering | Effekt |
|-----------|------------|--------|
| `checked` | `<input>` | Slått på |
| `disabled` | `<input>` | Deaktivert. Label og hjelpetekst tones ned |
| `aria-label` | `<input>` | Tilgjengelig navn når labelen ikke vises |
| `data-label-placement="right"` | `.ix-toggle-switch` | Labelen til høyre for switchen. Uten attributtet står den til venstre |

</TabItem>

### ToggleSwitchProps

| Prop | Type | Påkrevd | Standard | Beskrivelse |
|------|------|---------|----------|-------------|
| `label` | `ReactNode` | Ja, eller `ariaLabel` | | Synlig labeltekst |
| `ariaLabel` | `string` | Ja, uten `label` | | Tilgjengelig navn når labelen ikke vises |
| `description` | `string` | Nei | | Hjelpetekst under labelen. Pakker switchen i `<ix-field>` |
| `labelPlacement` | `'left' \| 'right'` | Nei | `'left'` | Hvilken side av switchen labelen står på |
| `checked` | `boolean` | Nei | | Kontrollert tilstand. Bruk sammen med `onChange` |
| `defaultChecked` | `boolean` | Nei | | Starttilstand når du ikke kontrollerer den selv |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | Nei | | Kalles med det native eventet. Les `event.target.checked` |
| `disabled` | `boolean` | Nei | | Deaktivert |
| `className` | `string` | Nei | | Klasse på rotelementet (`<ix-field>` når `description` er satt) |

Andre attributter, som `name`, `value`, `id` og `ref`, går rett til `<input>`. Det gjør at switchen virker i et vanlig `<form>` og med `register()` fra React Hook Form.

## Tilpasning med CSS

Bygger du switchen i egen HTML, holder det med klassen på wrapperen. Track og knott tegnes av labelen, så du trenger ingen ekstra elementer.

### Tilgjengelige klasser og selektorer

| Element | Selektor |
|---------|----------|
| Wrapper | `.ix-toggle-switch` |
| Input | `.ix-toggle-switch input` |
| Label, track og knott | `.ix-toggle-switch label`, `::before` (track), `::after` (knott) |
| Slått på | `.ix-toggle-switch input:checked + label` |
| Label til høyre | `.ix-toggle-switch[data-label-placement='right']` |
| Hjelpetekst | `.ix-toggle-switch [data-field='description']` |

### Eksempel: ren HTML

```html
<div class="ix-toggle-switch ix-w-full">
  <input type="checkbox" role="switch" id="wifi" name="wifi" checked />
  <label for="wifi">Wifi</label>
</div>
```
