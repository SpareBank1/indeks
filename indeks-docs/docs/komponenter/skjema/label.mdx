# Label

Label er ledeteksten til et skjemafelt.

## Egnet til

- Ledetekst koblet til et inputfelt


## Uegnet til

- Text uten tilhørende inputfelt

### Bruk med ix-field

`ix-label` er en CSS-klasse. Bruker du `<ix-field>`, trenger du den ikke — `<ix-field>` styler `<label>`-elementet inni seg automatisk:

```jsx live
<ix-field>
  <label for="konto-field">Kontonummer</label>
  <span data-field="description">11 siffer uten mellomrom</span>
  <div class="ix-text-field">
    <input id="konto-field" type="text" inputMode="numeric" />
  </div>
  <span data-field="error"></span>
</ix-field>
```

Bruker du ikke `<ix-field>`, legger du `ix-label`-klassen på `<label>`-elementet selv — som i «Bruk»-eksemplet over.

## Retningslinjer

Dette er reglene for labeltekst i Indeks. De gjelder alle skjemafelt: tekstfelt,
nedtrekkslister, søkefelt, checkboxer og radioknapper.

### Navngi dataen, ikke handlingen

1–3 ord er nok. Labelen sier hva feltet inneholder, ikke hva brukeren skal gjøre.

| Gjør dette | Ikke dette |
|------------|------------|
| Kontonummer | Vennligst oppgi kontonummeret ditt |
| E-postadresse | Skriv inn e-post |
| Fødselsdato | Dato |
| Land | Velg land |

### Navngi valget på checkbox og radioknapp

For checkbox og radioknapp er labelen navnet på alternativet, ikke oppfordringen til å
velge det. Da ser brukeren hva avhukingen betyr.

| Gjør dette | Ikke dette |
|------------|------------|
| Motta nyhetsbrev | Meld meg på nyhetsbrev |
| Privat | Velg privat |
| Bedrift | Trykk her for bedrift |

### Skriv med stor forbokstav og uten kolon

Labelen er ikke en overskrift og ikke en setning. Ingen kolon på slutten.

### Legg formatkrav i description

Ikke strekk labelen for å få plass til krav eller eksempler. Det hører i en description
under feltet.

| Gjør dette | Ikke dette |
|------------|------------|
| Label: "Kontonummer" + description: "11 siffer uten mellomrom" | Label: "Kontonummer (11 siffer uten mellomrom)" |

### Plasser labelen tett over feltet

Avstanden mellom label og felt skal være kortere enn avstanden mellom to felt. Da ser
øyet hvilken label som hører til hvilket felt, før noen leser et ord.

### Merk unntaket, ikke regelen

I banksammenheng er nesten alle felt påkrevd. Merk de valgfrie med "(valgfritt)" i
labelteksten, og la de påkrevde stå uten stjerne.

### Unngå forkortelser og intern sjargong

Skriv "Organisasjonsnummer", ikke "Org.nr.". Forkortelser kan du bruke når skjemaet er
laget for folk som jobber med feltet daglig, som regnskapsførere.

## Universell utforming

### Hva du selv må sørge for

- **Meningsfull labeltekst:** labelen skal forklare hva som skal fylles inn, ikke handlingen. "E-postadresse" er bedre enn "Skriv inn e-post"
- Koble label til input. Sett `for` (HTML) eller `htmlFor` (React) til ID-en på inputfeltet. Uten denne koblingen kan skjermlesere ikke assosiere labelen med feltet

## Props / API

<Tabs groupId="variant">
<TabItem value="html" label="HTML">

### `.ix-label`

Legg til klassen `ix-label` på et `<label>`-element:

```html
<label class="ix-label" for="input-id">Labeltekst</label>
```

`for`-attributtet kobler label til input. Uten `for` er labelen ikke programmatisk koblet til feltet.

</TabItem>
<TabItem value="react" label="React">

### LabelProps

| Prop | Type | Påkrevd | Beskrivelse |
|------|------|---------|-------------|
| `children` | `ReactNode` | Nei | Labelteksten |
| `htmlFor` | `string` | Nei* | Kobler label til input via `for`-attributt. *Alltid anbefalt |
| `className` | `string` | Nei | Ekstra CSS-klasser |
| `ref` | `Ref<HTMLLabelElement>` | Nei | Ref videresendes til `<label>`-elementet |

I tillegg støttes alle standard HTML label-attributter.

</TabItem>

## Tilpasning med CSS

Label har ingen egne CSS-variabler å overstyre. Typografien arves fra token-systemet:

| Egenskap | Token |
|----------|-------|
| Skriftstørrelse | `--ix-font-size-md` |
| Fontvekt | `--ix-font-weight-medium` |
| Farge | `--ix-color-foreground-main-default` |
| Linjehøyde | `1.2` |
