# Native

I hybridapper vises Indeks-komponenter i WebView-en til en native app. Brukeren skiller ikke mellom de to, og forventer derfor at web-delen oppfører seg som resten av appen.

## WebView-oppførsel

Uten tilpasning oppfører innholdet seg som en vanlig nettside. Tekst kan markeres ved langt trykk, elementer kan dras, og det ligger en merkbar forsinkelse på trykk. Ingen av de tre skjer i en native app.

Indeks har utility-klasser som slår av denne oppførselen, og som lar deg slippe tekstmarkering gjennom igjen der brukeren faktisk trenger å kopiere noe.

Se [Native (utility-klasser)](/docs/utility-klasser/native) for fullstendig oversikt over klassene `.ix-native`, `.ix-selectable` og `.ix-selectable-all`.
